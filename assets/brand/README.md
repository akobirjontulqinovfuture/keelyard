# keelyard brand

The mark is a **K** whose lower leg is a check: the keel of the project is proof.

| File | Use |
|---|---|
| `mark.svg` / `mark.png` | Main mark (dark tile). Works on light and dark backgrounds |
| `mark-light.svg` | Light tile, for dark surfaces where a dark tile disappears |
| `lockup-light.svg` / `lockup-dark.svg` | Mark + wordmark for light / dark backgrounds |
| `hero-light.png` / `hero-dark.png` (+ `.svg`) | README banner, switched with `<picture>` |
| `social-preview.png` | 1280×640 GitHub social preview |
| `favicon-*.png`, `favicon.ico` | 16, 32, 48, 180 (Apple), 192, 512 |

## Colors

| Name | Hex | Role |
|---|---|---|
| Ink | `#111111` | Tile, text on light |
| Paper | `#F6F5F0` | Letter K, text on dark, light page |
| Proof green | `#3DDC84` | Check on dark tiles |
| Proof green (light) | `#178A52` | Check / accents on light backgrounds |
| Muted | `#9A9A93` / `#5E5E58` | Secondary text on dark / light |

Type: Inter Tight Bold for the wordmark (converted to outlines in the SVGs, so no font is needed).

## Rules

- Keep clear space of at least a quarter of the tile width around the mark.
- Don't recolor the check, add gradients or effects, or stretch the mark.
- Smallest size: 16 px (`favicon-16.png` is tuned for it).
