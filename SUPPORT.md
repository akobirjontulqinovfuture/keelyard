# Getting help with keelyard

- **Something broke?** Run `keelyard doctor` first; it names most setup problems and how to fix them.
  Then check [Troubleshooting](https://akobirjontulqinovfuture.github.io/keelyard/troubleshooting/).
- **A bug:** open an [issue](https://github.com/akobirjontulqinovfuture/keelyard/issues/new/choose) with
  `keelyard --version`, your agent and its version, your OS, and the output of `keelyard doctor --json`
  (read it first and remove anything private).
- **Questions, ideas, show-and-tell:** [GitHub Discussions](https://github.com/akobirjontulqinovfuture/keelyard/discussions).
- **A security problem:** please don't open a public issue; see [SECURITY.md](SECURITY.md).
- **Want to contribute?** Issues labeled
  [good first issue](https://github.com/akobirjontulqinovfuture/keelyard/labels/good%20first%20issue) have a clear
  scope and a "done when". See [CONTRIBUTING.md](CONTRIBUTING.md).

keelyard is maintained by one person in their spare time. Expect a reply within a few days; there is no paid support.
